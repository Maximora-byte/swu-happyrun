# HappyRun 本地产品

2026-10-23 用户授权本地 Codex 开发和实测，并确认“尚未登录，先完成本地产品”。此版本提供本机中文工作台、真实 HTTP 调度、持久模拟任务、取消确认和显式停止恢复。它不会启动或操作步道乐跑，也不会写入 MuMu 的位置或传感器。

## 打开

Windows 交付文件夹中的 `Start-HappyRun.cmd` 会校验全部文件，使用已安装的 Python 3.13 创建独立运行环境，离线安装随包依赖，然后打开浏览器。不需要管理员、联网安装依赖、改 PowerShell 执行策略或 Root。文件夹可以移动；不要将运行环境与其他版本混装。

源码启动：

```powershell
uv sync --python 3.13 --frozen --extra server --extra agent
uv run --no-sync swu-happyrun desktop
```

安装 wheel 后在任意目录执行 `swu-happyrun desktop`。默认仅监听 `127.0.0.1:8765`。使用 `--port 8766` 可更换端口；`--data-dir <新的私有目录>` 明确选择另一个**合成工作区**，不改变任何 MuMu 身份或 journal。Windows 默认数据目录是当前用户 LocalAppData 下的 `HappyRunDesktop`，首次创建受保护的本人专用 ACL，已有目录不改权限。已有配置损坏、被修改或使用链接时拒绝启动，不自动重置。

启动器只在成功监听后打开带一次性会话凭据的本机页面；页面立即从地址栏和历史中移除此值，并换取 HttpOnly、SameSite=Strict 的会话 Cookie。ADMIN 和 AGENT token 不传给页面、不保存在磁盘或浏览器，也不输出到终端。刷新页面保留当前会话，服务重启后重新运行启动器建立新会话。`--no-browser` 用于无交互运行/健康检查，新浏览器无法靠裸 URL 建立首次会话。

## 操作

1. 等待“控制服务：运行正常”“本地执行代理：已连接”。
2. 点击“开始本地模拟”。工作台使用约 22 米合成路线与 2 m/s 配速，约 12 秒后显示“模拟完成”。路线不是西大地图或学校正式规则。
3. 运行中可“请求停止”；先显示等待停止确认，代理确认后才显示“已取消”。
4. 记录自动保存在本机；刷新或正常重启不丢失历史。发生中断时保持需要处理，不自动重新运行；“确认结束待处理任务”只批准 stop_only，不进行重跑。
5. 关闭启动器中的服务进程（Ctrl+C）会请求代理退出。服务退出后页面显示连接中断，不代表一个未确认任务已经停止；下次启动按原状态处理。

工作台只管理自己的合成设备、固定本地配置与路线；不接收物理设备 ID、自定义上传地址或真实应用版本。原 `/console/` 与 `/api/v1` 的 Bearer 鉴权保持独立。原生 Android APK 的本地模拟仍是独立设备内流程；本版本没有把桌面 Cookie 当作 Android 远程登录凭据。

## 验收范围

真实 HTTP 与浏览器检查可证明本机软件闭环；MuMu 安装/操作证明自身 APK 的相应流程。MuMu 原生虚拟位置、连续轨迹、学校规则、步道乐跑页面与有效记录仍需各自验收。旧 Python 3.11 访问违规 #110 不因本版本采用 3.13 而关闭。
