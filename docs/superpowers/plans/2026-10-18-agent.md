# Windows 执行端实施计划：本地 Codex

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 提供 MuMu 能力诊断、可恢复任务代理和有证据的步道乐跑版本适配。

**Architecture:** 平台驱动通过显式能力向执行引擎提供设备动作；引擎持久化意图并服从服务器租约；乐跑界面由版本适配器解释。所有硬件操作可替换为 fake driver。

**Tech Stack:** Python 3.11+、Pydantic v2、HTTPX、SQLite 本地日志、MuMuManager、ADB、pytest。

**Spec:** [设计](../specs/2026-10-18-swu-happyrun-design.md)、[v1 契约](../../contracts/control-plane-v1.md)、[总计划](2026-10-18-development.md)。

## Global Constraints

- 本机目标 MuMu 6.8.4.0 / Android 15，不能把参考项目 Android 12 的坐标补偿或控制参数直接设为已验证。
- Python 3.11+，请求 5 秒超时、心跳 10 秒、租约 30 秒；时间推进用单调时钟。
- 对未知版本、未知坐标或应用页面返回待处理；设备截图和原始数据留在 `local/`。
- 不改 Root、安全设置、其他用户模拟器实例；指定实例与设备锁必需。

## Review Focus

1. L0：安装目录有空格/中文、多个实例、CLI 非零返回时诊断准确。
2. L1：坐标系未知、经纬度颠倒、非有限数不能下发设备。
3. L2：进程在开始动作之后退出，恢复不能再次开始。
4. L2：续租失败或取消时，工作线程必须停止且不得赶进度连发指令。
5. L3：未知界面、动态点缺失或上传结果不明不能报成功。
