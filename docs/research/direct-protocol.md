## 最小输入请求

[Issue #9](https://github.com/Maximora-byte/swu-happyrun/issues/9) 已请求实际版本与脱敏样本。接口方向另外需要：

- 每段操作的目的、顺序、客户端版本和时间（不含身份秘密）。
- URL 路径结构、HTTP 方法、字段名/类型和脱敏响应；移除 Authorization、Cookie、密码、签名值、设备唯一标识、账户信息和连续定位数据。
- 开始、结束、上传与查询之间的任务/会话关联规则，以合成占位标识展示关系。
- 正常、超时、重复请求、结果待定的真实观测；没有观测的情况写未知。

不要求在 Git 或群消息提供可复用会话 token、密码、私钥或原始抓包。不得绕过 TLS 校验、应用安全机制或修改设备 Root/网络安全设置来取样。本人已有、合法取得的样本先在本地脱敏；账户登录与授权由本人完成。

## 实现门槛

先验证脱敏样本的一致性并固定版本契约，再以离线 fixture 测试解析/签名接口边界和错误处理。取得明确授权、测试环境/本人会话和可验证协议后才考虑在线验证；确认未知结果不会自动重新开始或上传。

任何适配器仍必须服从共享状态机、持久化 intent、租约/fence、取消确认、受限恢复和记录核验。接口返回成功不等于学校认可记录，必须独立回查。参考项目、他校小程序与作者成功率仅为研究线索，不是西大有效记录证据。

该路径保留为后续工作，当前没有足够证据断言永久可行或永久不可行；不会阻塞控制平面与 fake 联调交付。

## Task 7 离线输入门槛（2026-10-19）

共用 [接入清单与元数据校验器](../onboarding.md)，另需本人合法取得的版本专用
HTTP 方法/路径结构、字段类型、时间戳/nonce/签名覆盖范围与规范化语义、错误及
幂等规则。只交语义和人工脱敏的结构；签名值、密钥、token、账号、原始请求响应
及连续点位不进仓库。真实点位来源和 CRS 必须单独明确，不从接口字段名猜测。

目前尚未取得足够协议/签名语义，未实现该版本直传或记录查询适配器。此门槛不会
计算真实签名、构造正式上传或在线试探。`pending`、`unknown`、超时和无法关联
本次 job/session/profile/app_version 的记录均不能作为成功依据。离线 synthetic
回归不证明学校接受；执行能力仍关闭，直到版本方案和独立现场验收完成。
