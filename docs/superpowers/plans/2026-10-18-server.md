# 服务器实施计划：云端 ChatGPT Dot

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 交付可独立运行、可持久化恢复的任务调度服务器，并通过模拟代理验证协议。

**Architecture:** FastAPI 处理认证与请求，SQLite store 原子保存任务、租约和事件，单个调度器生成日程实例。设备执行始终在代理端。

**Tech Stack:** Python 3.11+、Pydantic v2、FastAPI/Uvicorn、SQLite、HTTPX/TestClient、pytest。

**Spec:** [设计](../specs/2026-10-18-swu-happyrun-design.md)、[v1 契约](../../contracts/control-plane-v1.md)、[总计划](2026-10-18-development.md)。

## Global Constraints

- 只能直接修改 `src/swu_happyrun/server/`、`tests/server/`、`deploy/` 及对应服务器文档；共享模型、依赖与 CI 先协调。
- Python 3.11+，`/api/v1`，HTTP 超时 5 秒、心跳 10 秒、租约 30 秒；UTC / Asia/Shanghai。
- SQLite 初版单进程、单调度器；独立 ADMIN/AGENT token；AGENT 绑定身份。
- 不依赖 Windows、ADB、MuMu 或真实乐跑账号；不得生成设备验收结论。

## Review Focus

1. S0：请求重放和同幂等键不同载荷必须有不同结果。
2. S1：并发领取和旧 fence 不能产生两个有效执行者。
3. S1：取消断线任务不能伪装成已经停止。
4. S2：日程跨 UTC 日期、重启与时窗过期不能重复创建或补跑。
5. S0/S2：他人任务、错误体和容器日志不得泄漏令牌与私有配置。
