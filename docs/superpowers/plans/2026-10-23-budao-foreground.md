# 乐跑前台与持续位置观察实施计划

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 用户在 MuMu 5 切换到官方步道乐跑时，本地轨迹仍有独立的新鲜 GPS 读回；依据实际页面继续应用内联调。

**Architecture:** 保持现有 nonce/boot/时间与设备锁协议；仅 SELF_PROBE 增加非导出的 location 前台服务，由已有可见 Activity 内的 instrumentation 显式启动并确认，结束观察时显式停止。普通 APK 不含此服务及其权限。乐跑账号由本人登录，版本与界面取实际样本。

**Tech Stack:** Python 3.11+、Android API 26–35 / Java 17、MuMu 6.8.4.0、协议 v1。

**Spec:** [总设计](../specs/2026-10-18-swu-happyrun-design.md)、[已有 MuMu 计划](2026-10-23-mumu-product.md)。用户 2026-10-23 继续授权至少能在乐跑内模拟，官方应用安装后由本人手动登录。

## 约束与检查重点

- 不增加 Root、AppOps、后台位置权限或自动重启；使用系统正常 location 前台服务和通知。
- 服务仅 SELF_PROBE 存在，非导出、不监听外部广播，不记录或发送账号。
- 观察启动、服务就绪和注销/停止分别确认，未知状态不能冒充成功。
- 主机仍先持久化意图，再写入定位；中断/不确定不得自动重放。
- 精确版本和页面未知时不猜选择器；应用内轨迹与学校有效记录分别验收。
