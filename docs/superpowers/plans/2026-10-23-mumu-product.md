# MuMu 实际定位与轨迹交付

用户本轮明确要求今晚包含 MuMu 实际定位与轨迹，尚未登录步道乐跑。以此覆盖旧分工；本轮由本地 Codex 实现和实测。保留控制协议 v1，不改学校执行和记录成功门槛。

## 实施范围

1. Android 测试 APK 增加明确请求才运行的连续 GPS 观察窗口。只读自有应用已授权的 GPS，不安装模拟 provider、不启用 Root/Xposed。使用随机 nonce 私有文件，包含 boot、递增采样序号和单调时钟；窗口有截止时间和停止文件。原普通 APK 和测试路径继续可用。
2. Windows 本地专用控制器发现真实实例、版本、ADB 和 boot，绑定正在运行的唯一实例。定位命令依据 MuMu 官方 CLI 和本机 6.8.4.0 帮助。每次写入前持久化意图，单个发送线程、单命令在途；异常写入不自动重试。私有持久记录和跨进程设备锁阻止新会话绕过未决状态。
3. 两个真实来源的不对称路线点校准输入/读回映射。未取得新鲜且匹配的位置不能开放轨迹。轨迹按单调时钟推进；暂停、继续、停止必须有单独观测。停止含义是本产品发送线程结束且在途命令结束，最后定位保留；不声称已清除 MuMu 的虚拟定位状态或取得学校记录。
4. 工作台增加独立 MuMu 面板：实例选择、私有路线文件导入、校准、启动、暂停、继续、停止、读回误差和轨迹显示。沿用本地 session、Origin/Host 认证，不接入公开 server 的学校 device 任务。
5. 单元/故障测试覆盖版本、绑定变化、陈旧采样、取消/停止和重启未决状态；真实 QA 实例 5 验证定位、连续轨迹、暂停/继续、停止后的稳定窗口。截图、路线、设备身份和数据库只存私有目录；报告仅脱敏摘要。

## 既有门禁

原有 enrollment/runtime/CLI 生产门禁保持关闭，不能借本地实验声称它们已经通过。此次新增的独立本地模式明确命名为 MuMu 轨迹工具，只向用户选定、当前绑定、已校准的实例发送单点定位；不启动、操作或上传步道乐跑记录。

## 当前状态

- 本地模拟工作台和普通 Android APK 已有实测基线。
- 源代码现场：14 次定位与新鲜 GPS 读回、暂停/继续、稳定停止通过，最大读回偏差约 0.95m；故意进程中断后 5→5 次写入、无自动重跑、显式关闭匹配实例通过。交付包整条路线与准确提交绑定仍待最终复测。
- Android 15 必须在 instrumentation 内保留自身前台 Activity；GPS provider 就绪独立于 manager/boot 完成。当前输入映射为经实际观察支持的 BD09 假设，仍每会话两点校准。暂停时系统保留位置与新 GPS 样本分别记录。
- 官方来源：https://mumu.163.com/help/20240726/35047_1170006.html （本机已读取 2026-10-23，定位命令及 gyro 单位；不含轨迹队列/停止保证）。
