# HappyRun 网页控制台

控制台是服务器同源的中文静态页面，无 CDN、外部字体或前端构建依赖。打开服务器的 `/console/`（根路径 `/` 会重定向）。静态页面本身公开，私有 API 仍要求 ADMIN 令牌。

## 使用顺序

1. 启动已配置的 HappyRun 服务器，在本机回环 HTTP 地址或可信 HTTPS 页面打开控制台。普通局域网 / 公网 HTTP 页面拒绝发送令牌；不会通过页面配置另一个服务器地址。
2. 输入当前服务的 ADMIN 令牌。连接会实际请求 `GET /api/v1/devices` 核实管理员权限；health 成功不表示认证成功。
3. 在“设备登记”确认已有设备与代理归属。没有登记时，填写代理实际使用的设备 UUID 和代理 UUID。登记不是启动设备，当前 API 也不提供设备在线或能力状态。
4. 展开“创建任务”，导入已有的完整 JobSpec JSON，或手动填入已核实的配置 UUID/revision、路线 UUID/revision、设备 UUID 与时间窗口。默认 simulation。前端不生成学校规则、配置摘要、选择器或路线。
5. 确保执行代理持有对应 ID 和 revision 的配置文件，再提交任务。控制台不会上传学校或路线配置文件，也不会启动代理、MuMu 或 ADB。
6. 在列表中打开详情，或使用完整 UUID 查询。列表每页 25 条，通过服务返回的游标加载更早任务。需要新的当前状态时点击刷新；无后台自动轮询。

所有表单 datetime-local 值都解释为中国标准时间 UTC+8，与电脑时区无关，提交前转换为带 Z 的 UTC 时间。导入 JobSpec 的 UTC 时间转换为 UTC+8 显示。输入会校验真实日历日期，不会把不存在的日期自动挪到下个月。此表单仅支持整秒；导入非零小数秒时明确拒绝，要求用户先调整原文件，不会静默截断精度。配置 revision 是原文件的规范摘要，不是随机 ID。

## 状态与安全边界

- `completed` 显示“模拟完成”，不代表学校有效记录。
- `succeeded` 是代理上报的记录核验结果，控制台不独立证明学校后台认可。
- 实机请求会明确警告当前候选未支持真实乐跑执行；创建前再次确认，不把创建成功当作可用性。
- 取消前明确确认，显示所见 revision，并重新读取任务检测已发生的变化。既有 cancel API **没有原子 expected_revision 检查**，前端读取无法消除读取与取消之间的竞争；未改写该协议。响应为 cancelling / needs_attention 时仍需等待停止确认。
- 只有 needs_attention 提供恢复按钮。恢复发送服务器当前 `expected_revision` 与选择的 action；409 要求用户刷新再确认。只核验不会重跑或重传，只停止不会重新运行。重新预检仅在所见阶段为 leased/preflight/ready 且未有取消意图时展示，服务器继续做历史副作用等最终校验。
- 日程仅查看与启停已有 ScheduleSpec。启停先重新读取并比较模板，再以原完整模板切换 enabled。协议无日程版本锁，跨客户端并发仍可能发生；不宣称原子防覆盖。启停仅影响未来尚未生成任务，不取消已有任务。

## 创建请求不确定时

创建使用内存中的随机幂等键。成功响应必须先通过 JobView 结构验证；无效的 200/201 响应同样视作未确认。超时、断线或其他未确认响应后保留原键与原 JSON 请求，锁定字段和导入，按钮变为“用同一请求重试”。不会静默更换 key 或因为编辑而创建第二个任务。创建/重试和放弃操作共用互斥锁，包含确认对话框等待期间；请求在途时不能放弃并切换为另一请求。首次请求收到明确未修改服务状态的 403/422 时解锁输入，用户可修正后再次提交。若更早请求已经结果不确定，随后收到 403/422 仍保留原键，避免误判此前是否成功。也不会自动重试取消、恢复或日程变更。

要更改未确认请求，先刷新任务列表核对，再点击“处理未确认的创建”并明确确认放弃。之后提交才会生成新 key。退出或刷新会丢失内存中的重试记录；页面离开前提示尚未确认创建，但浏览器不保证展示离开确认，务必先核对。

## 令牌与数据

- 令牌输入是 password；发送连接请求前清空输入，只在 JS 闭包内存中保留令牌。
- 不使用 localStorage、sessionStorage、Cookie、URL 参数或日志保存令牌。请求使用同源固定 API、Authorization header、credentials omit、cache no-store，禁止跟随重定向。
- 退出、页面离开或任意 401 会中止在途请求，递增会话代数并清空令牌、私有列表、详情、表单与确认对话框。迟到响应无法重新填回旧会话内容。
- 动态 API 文本通过 textContent / DOM 节点渲染，不使用 innerHTML。页面 CSP 仅允许同源脚本、样式与连接，不允许 inline / eval。
- 使用可信 HTTPS / 本机回环服务，避免共享浏览器会话。浏览器开发者工具本身能看到当前页网络请求；本页面不是隔离恶意浏览器扩展或同源恶意脚本的保险箱。

## 验证

`node --check src/swu_happyrun/server/web/app.js` 检查 JavaScript 语法。

`node tests/console/test_console_helpers.cjs` 执行生产代码中的纯函数，检查输入校验、真实日历日期、UTC+8 转换、JobView 响应结构和安全源约束，并通过 DOM/fetch 测试环境执行整个生产脚本，验证无效成功响应保留同一幂等请求、明确拒绝后可编辑。此测试不替代真实浏览器验收。

`python tests/console/test_console_browser.py` 使用系统 Chromium 和已安装 Python Playwright，启动独立回环静态 fixture，检查手机 375px 布局、实际连接、令牌输入清空、无 Web Storage 和退出清屏。测试依赖仅用于开发，不是服务器运行依赖。

本地环境未执行 Chromium 实测；真实浏览器结果以同一候选 HEAD 的 Actions `console-browser-qa` 及 PR 记录为准，不能把脚本存在当作浏览器验收通过。

未实现：日程创建/完整模板编辑、配置上传、能力观测/在线监控、代理进程管理、实时推送、实机适配和学校记录独立验收。
